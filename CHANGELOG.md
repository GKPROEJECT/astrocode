# Changelog

All notable changes to the "astrocode" extension will be documented in this file.

## [1.2.5] - 2026-05-26
- Some errors have been fixed.

## [1.2.4] - 2026-05-26
- Added **Corner Radius** control to adjust the code card roundness.
- Added **Window Title** feature to customize the title bar text.
- Added 3 new themes: **Vitesse Light**, **Catppuccin Mocha**, and **Rosé Moon**.
- Fixed a redundant activation event warning in `package.json`.
- Improved localization for all new settings in English, Spanish, and French.

## [1.2.0] - 2026-05-14
- Added multi-language support (i18n) for the entire extension.
- Correction of icons in presets
- Sidebar panel now automatically adapts to the user's system or VS Code language.
- Metadata and command titles are now localized.

## [1.1.9] - 2026-05-13
- Renamed "Twitter Card" preset to "X" with the new logo.

## [1.1.8] - 2026-05-13
- Added 7 new visual themes: Tokyo Night, One Dark, Monokai, Rosé Pine, Material Ocean, Vitesse Dark, and Poimandres.

## [1.1.7] - 2026-05-13
- Implemented Content Security Policy (CSP) to comply with VS Code security standards.
- Changed `html-to-image` loading from CDN to local for better stability.
- Added error handling (try-catch) for Shiki highlighting and panel rendering.
- Adjusted minimum VS Code engine version for better compatibility.

## [1.1.6] - 2026-05-13
- Updated README with Quick Presets information.

## [1.1.5] - 2026-05-12
- Visual redesign of the "Reset" button.
- Sidebar spacing adjustments for better UX.

## [1.1.4] - 2026-05-12
- Fixed clipping issue during image export.
- Improved stability for high-resolution captures.

## [1.1.3] - 2026-05-12
- Performance improvement: Sliders now update the preview instantly.
- New value indicators for Padding, Shadow, and Font.
- Added "Reset" button to restore settings.

## [1.1.2] - 2026-05-12
- New presets: Facebook Post (1.91:1) and TikTok Video (9:16).

## [1.1.1] - 2026-05-12
- Adaptive presets: now adjust size and proportions for each platform (Twitter, GitHub).

## [1.1.0] - 2026-05-12
- Added **Quick Presets**: Twitter Card, GitHub README, Dark High-Res, and Pure Minimal.
- Improvements to the sidebar interface.

## [1.0.4] - 2026-05-12
- Fixed repository paths and icon in README.

## [1.0.3] - 2026-05-12
- README adjustments and icon optimization.

## [1.0.2] - 2026-05-12
- Minor bug fixes.

## [1.0.1] - 2026-05-12
- Stability improvements.

## [1.0.0] - 2026-05-12
- Initial release.
