# AstroCode 📸

Convert your code into clean, high-quality images directly from Visual Studio Code.

AstroCode is designed for developers who share their work, create documentation, or generate technical content, allowing you to export professional code captures in seconds without leaving the editor.

---

## ✨ Features

- **High-Fidelity Highlighting**: Powered by **Shiki** for accurate and beautiful syntax highlighting.
- **Modern Themes**: Includes popular themes like Dracula, GitHub Dark, Nord, Tokyo Night, Catppuccin Mocha, Rosé Pine, and Vitesse Light.
- **Window Customization**: Adjust **Corner Radius** and set a custom **Window Title** for your captures.
- **Quick Presets**: Optimized formats for X (Twitter), GitHub README, and high-resolution exports.
- **Design Control**: Fine-tune padding, shadows, and font size in real-time.
- **High Resolution**: Export as "retina-ready" PNG files.
- **Seamless UX**: Integrated sidebar interface that stays out of your way.

---

## ⚡ How to Use

1. **Select** the code you want to capture.
2. Open the command palette (`Cmd+Shift+P` / `Ctrl+Shift+P`).
3. Search and run `AstroCode: Capture Selection`.
4. **Customize** the style in the sidebar.
5. **Export** your image as a PNG.

---

Supports 40+ languages including:
